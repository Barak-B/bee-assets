# site-tools — נוסחאות המחשבונים לאתר barak-e.com

מודולי TypeScript טהורים (בלי UI) לארבעת המחשבונים החדשים בתוכנית האתר (שלבים 2–3). כל מודול בדוק ב-Vitest, ומוכן להעתקה לאתר (Astro + React islands) כשהלולאה של V2 תגיע לשלב הזה.

| מודול | מה הוא עונה | מקור הכללים | מצב |
|---|---|---|---|
| `connection.ts` | האם החיבור מספיק למערכת, לאיזה חיבור לשדרג, מונה ייצור, מגבלת הזרמה, מדידה ישירה/משני זרם | אמות מידה 35כ2, 35כ3(י) | כללים מאומתים במשרד |
| `storage.ts` | מה נדרש לרישוי סוללה לפי קיבולת | ספי האתר: 20 / 100 / 600 קוט״ש | **לאמת מול מקור רשמי** |
| `ev.ts` | איזו עמדת טעינה מתאימה לחיבור, לנסועה ולזמן החניה, והאם צריך בקר עומסים | חישוב הנדסי | לבדיקת ברק |
| `sizing.ts` | פאנלים (DC) מול ממיר (AC): יחס עד 200%, מדרגת בית עד 15 קילוואט AC, הצעת ממיר | ברק, 25.10.2026 | לבדיקה לפי דגם הממיר |
| `tariff.ts` | "שעון 2026": כמה עולה לחכות ל-2027 | גלובס 19–20.10.2026, טיוטת רשות החשמל (הערות עד 10.11.2026) | **טיוטה, להציג כך** |

דוגמה: 10 קילוואט בתל אביב (1,718 קוט״ש לקילוואט). בקשה ב-2026 מניבה כ-196,600 ₪ על פני 25 שנה. בקשה ב-2027 מניבה כ-150,900 ₪ על פני 20 שנה. ההפרש הוא כ-45,700 ₪, ובעיר עם תוספת עירונית כ-70,300 ₪. הסכומים נומינליים ולא כוללים את רכיב שער החליפין.

```
npm install
npm test
npm run typecheck
```
