# מנוע התכנון — מפת יכולות, ציון ותוכנית גלים

השוואה מול הכלים המקצועיים: Ecodial, ABB DOC, SIMARIS, Hagercad, Caneco, ETAP (חשמל מתח נמוך) ו-PVsyst, PV\*SOL, Aurora, OpenSolar, HelioScope, SolarEdge Designer, FusionSolar (PV). הדרישה הישראלית נלקחה מ-gov.il (היתר הפעלה למתקן PV עד 630 kW), מהצעות חיבור של חברות החלוקה וממסמכי רשות החשמל. סעיפי תקן שלא אומתו מול עותק התקן מסומנים †.

## מה כבר יש (אחרי גל 1)

- **חישובי מתח נמוך:** כושר הולכה IEC 60364-5-52 (B1, C, E, D1; PVC/XLPE; 1.5–240 ממ"ר), מקדם טמפרטורה באוויר ובקרקע, מקדם קיבוץ, מפל מתח עם ריאקטנס, קצר מקסימלי בלוח (IEC 60909 c=1.1), קצר מינימלי בקצה ותנאי ניתוק TN, כושר ניתוק, I²t, Ib ≤ In ≤ Iz, PE מינימלי.
- **PV:** חלון אורך מחרוזת (Voc ב-−3°C, Vmp בקור ובחום), זרם ומספר מחרוזות ל-MPPT, DC/AC, נתיכי מחרוזת ודירוגם, כבל מחרוזת, מפל מתח DC, בחירת חתך אוטומטית.
- **פלט:** חד-קווי, חזית לוח, דף חישובים AC+DC, כתב כמויות עם אותיות IEC 81346, DXF/PDF/CSV, שירות HTTP וסטודיו בדפדפן.

## הפערים לפי עדיפות, ומה בכל גל

### גל 2 — הגנות והתאמה לחח"י (P1)
1. **גודל חיבור מול הספק מותקן**: √3·400·I מול הספק ה-AC, הגבלת הזרמה, סיווג קטן / בינוני / מ"ג (630 kW), התראה כשצריך הגדלת חיבור.
2. **בחירת סוג פחת לפי הממיר** (A / B / ללא, לפי הצהרת היצרן, 712.531.3.101†) ופחת סלקטיבי (S, יחס IΔn ≥ 3).
3. **מגיני מתח יתר DC/AC**: Ucpv ≥ Voc מרבי, Type 1/2 לפי מערכת ברקים, אורך קריטי L_crit (712.443†).
4. **אגירה ולוח חיוני**: קצר מינימלי במצב אי (הממיר נותן 1.5–2·In), ממסר N-PE, הגנת DC לסוללה לפי זרם הקצר שלה.
5. **שער רישיון**: סוג רישיון החשמלאי/המתכנן ודרגת הבודק לפי גודל החיבור (‡ לאמת בתקנות הרישוי).

### גל 3 — נגישות למי שאינו מתכנן (P1)
1. טופס pv-connection בסטודיו (היום רק house-pv), עם טבלת MPPT.
2. רמזור לכל ממצא וכפתור "תקן" (למשל להגדיל ל-6 ממ"ר, להחליף לפחת Type B).
3. הסבר "למה" לכל ערך שהמנוע בחר.

### גל 4 — תפוקה וכלכלה (P1/P2)
1. PVGIS (`/api/v5_3/PVcalc`) לייצור שנתי וחודשי לכל חזית, עם הפסדים בסיסיים.
2. מפל הפסדים (טמפרטורה, כבלים לפי החישוב, ממיר, קיטום DC/AC).

### גל 5 — תיק הגשה ישראלי (P1)
1. תוכנית הארקה וחיבור לפסי השוואת פוטנציאל.
2. גיליון שילוט (DC, מקור הזנה נוסף, מפסק ראשי PV).
3. טופסי מסירה לפי IEC 62446-1 (רציפות PE, קוטביות, Voc/Isc לכל מחרוזת, בידוד ≥ 1MΩ).
4. הרכבת PDF אחד בסדר שחח"י מבקשים, עם בלוק חתימה של המתכנן.

### P2/P3 (אחר כך)
מקדמי ביקוש ובו-זמניות, סלקטיביות לפי עקומות יצרן (TCC), back-up/cascading, פיזור חום בלוח (IEC 61439), נייטרל עם הרמוניות, צל ופריסה על הגג (BEE-Scan), P50/P90.

## לאמת לפני שמסתמכים
- טבלאות D1 וטבלאות 150–240 ממ"ר (מהזיכרון, לאמת מול IEC 60364-5-52:2009).
- מקדמי נתיך IEC 62548 (מהדורת 2016 מול 2023).
- ערכי I²t של class 3 (EN 60898-1 נספח ZA).
- טבלת EN 50618 לכבל סולארי.
- גבולות רישוי ובודקים, וסף 630/700 kW.
