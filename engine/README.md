# bee-cad — מנוע ה-CAD של ברק הנדסת חשמל (שלד v0.1)

מודל תכנון אחד (JSON / YAML) → DXF שנפתח ב-AutoCAD / GstarCAD (ומומר ל-DWG במשרד) עם:

- **חד-קווי (E-xx)** — ארון מונה חח"י, מפסק ראשי, פס צבירה, קבוצות פחת ומעגלי קצה, הזנות לממיר / אגירה / לוח חיוני, פסי PE/N, מקרא, הערות, סיכום מאמ"תים לפי מופע.
- **מבנה לוח (E-Pxx)** — חזית דלת פתוחה עם מסילות DIN ורוחבי מודול 18 מ"מ, חתך צד, מידות (ישויות DIMENSION אמיתיות), נתוני הלוח, טבלת ציוד עם מיקום X לכל רכיב.

שני הגיליונות נקראים מאותו מודל, כך שתג / דירוג / מספר מעגלים לא יכולים להיות שונים בין החד-קווי לחזית.

## הרצה

```bash
cd engine
pip install -e ".[dev]"
bee-cad render examples/house_karka.json --out out/house --png
bee-cad check examples/house_karka.json          # בדיקות תכנון, הודעות בעברית (--json לאפליקציה)
bee-cad bom examples/house_karka.json --out bom.csv
bee-cad new examples/brief_house_pv.yaml --out out/new/design.json --render out/new   # תקציר קצר → סט מלא
python -m pytest -q
```

`render` מריץ את הבדיקות לפני השרטוט ומדפיס אותן; עם `--strict` הוא לא משרטט כשיש שגיאות. מפל מתח שלא הוזן מחושב ומודפס בחד-קווי.

### מה נבדק

| קוד | רמה | מה |
|---|---|---|
| `CABLE_OVERLOAD` / `CABLE_UNCHECKED` | שגיאה / אזהרה | מפסק גדול מכושר ההולכה של הכבל (IEC 60364-5-52 נספח B, נחושת, בלי מקדם קיבוץ; מקדם טמפרטורה לפי `cable.ambient_c`; B1 למעגלים סופיים, C ליציאות ולכבל ההזנה, אלא אם `cable.method`). אלומיניום וחתכים מחוץ לטבלה מסומנים לבדיקה ידנית |
| `DU_HIGH` / `DU_COMPUTED` / `DU_MISMATCH` | אזהרה / מידע | מפל מתח מהמונה עד קצה המעגל מעל 3% בתאורה או 5% בשאר (IEC 60364-5-52 G.52.1); זרם מ-`load_kw` או מהספק הממיר, אחרת דירוג המפסק |
| `ICU_LOW` / `IK_BOARD` / `NO_IK` | שגיאה / מידע | כושר ניתוק קטן מזרם הקצר המקסימלי בלוח (IEC 60909, c=1.1, מתוך `supply.ik_ka`) |
| `DISCONNECT` | שגיאה | בשיטת TN: זרם הקצר המינימלי בקצה המעגל (c=0.95, ρ חם) לא מגיע לסף הניתוק המגנטי (B 5In, C 10In, D 20In); מעגל מאחורי פחת 30mA מסומן כמידע בלבד |
| `POLES_PHASE`, `NO_PHASE`, `NO_CABLE` | שגיאה / אזהרה | מעגל תלת-פאזי עם מפסק חד-קוטבי, מעגל בלי מופע או בלי כבל |
| `DUP_TAG`, `BAD_REF` | שגיאה | תג כפול בלוח, יציאה ללוח או רכיב שלא קיים |
| `RCD_SOCKETS`, `RCD_UNDERRATED` | שגיאה / אזהרה | מעגל שקעים בלי פחת או RCBO של 30mA, פחת קטן מהמעגל אחריו |
| `SELECTIVITY` | אזהרה | יציאה שלא קטנה מהמפסק הראשי (לא כולל הזנה מממיר / מצבר / גנרטור) |
| `PHASE_BALANCE` | אזהרה | פער של יותר מ-35% בין המופעים, וגדול מהמעגל החד-פאזי הגדול |

קודי יציאה: 0 תקין, 3 קובץ לא קריא, 4 יש שגיאות תכנון. `check --json` מחזיר גם שגיאת קובץ כ-JSON.

### תבנית "בית + PV" (`bee-cad new`)

ממלאים תקציר של כ-30 שורות (`examples/brief_house_pv.yaml`): לקוח, גודל חיבור, ממיר, אגירה, ורשימת מעגלים בשמות רגילים ("שקעים — סלון", "מזגן", "עמדת טעינה"). המנוע בוחר מפסקים וכבלים לפי סוג העומס, מגדיל חתך לפי אורך כדי לעמוד במפל המתח, מחלק מופעים, מקבץ מעגלים מאחורי פחתים (עד 7 לכל פחת, עמדת טעינה בפחת Type B משלה), מחשב את Q-INV (1.25 × זרם הממיר) ואת הכבל שלו, בונה לוח חיוני, בוחר ארון עם 25% מקום פנוי וכותב הערות.

כתב הכמויות מקבץ פריטים זהים ומסמן כל שורה באות IEC 81346-2 (QA מפסק, FB פחת, FA מגן מתח יתר, FC נתיך, PG מונה; QA למפסקים כמו ב-Ecodial).

הפלט: `out/house/house_karka.dxf` (R2018, mm) + PNG לכל גיליון. `--mode shx` כותב עברית בסדר ויזואלי (הפוך) לגופני SHX ישנים (`HEBREW.SHX` וכד').

### סטודיו בדפדפן (`bee-cad serve`)

`bee-cad serve` פותח מסך ב-http://127.0.0.1:8765 בלי תוכנה נוספת: טופס התקציר מימין (לקוח, חיבור, ממיר, אגירה, מעגלים עם אורך, לוח חיוני), ומשמאל החד-קווי, הלוחות ודף החישובים כ-SVG, הממצאים, טבלת החישובים וכתב הכמויות. כל שינוי בטופס מחשב מחדש תוך כשתי שניות. כפתורים מורידים סט PDF, DXF, כתב כמויות CSV ו-JSON. אותו API (`POST /api/design`, `POST /api/export?fmt=pdf|dxf|csv|json`) יכול לשמש את האפליקציה.

הטבלאות (IEC 60364-5-52), גבולות מפל המתח והמקדם 1.25 הם ברירות מחדל הנדסיות ולא דרישת חוק; המהנדס המתכנן מאשר את שיטת ההתקנה.

## מבנה

| קובץ | תפקיד |
|---|---|
| `bee_cad/model.py` | המודל: `Design` → `Board` (supply, incomer, busbar, groups → circuits, feeders, enclosure) + `Node` (ממיר, מצבר, PV, גנרטור, שנאי) + `TitleBlock` |
| `bee_cad/symbols.py` | סמלי IEC 60617 כבלוקים (`BEE_MCB_4P`, `BEE_RCD_4P`, `BEE_SPD`, `BEE_METER_KWH`, `BEE_CT`, `BEE_INVERTER`, `BEE_BATTERY`, `BEE_PV`, `BEE_TRANSFORMER`, `BEE_GENERATOR`, …) |
| `bee_cad/sheet.py` | גיליון A3, רשת 12×8, כותרת עליונה, בלוק כותרת וטבלת מהדורות בסגנון המשרד; סגנונות טקסט `BEE-HEB` (Arial), `BEE-LAT` (isocp), `BEE-HEB-SHX` |
| `bee_cad/layers.py` | תקן שכבות `BEE-*` (צבע ACI, עובי קו, סוג קו) |
| `bee_cad/sld.py` | פריסת החד-קווי (עמודות דטרמיניסטיות) |
| `bee_cad/panel.py` | מילוי מסילות DIN לפי סדר החד-קווי, חזית וחתך, טבלאות |
| `bee_cad/text.py` | עברית: סדר לוגי (TTF) / סדר ויזואלי (SHX) בעזרת python-bidi; פיצול שורות עברית/לטינית |
| `bee_cad/calc.py` | פענוח כינוי כבל, כושר הולכה, מפל מתח, אותיות IEC 81346 |
| `bee_cad/checks.py` | כללי התכנון וההודעות בעברית |
| `bee_cad/templates.py` | תבניות עבודה: תקציר → תכנון מלא |
| `bee_cad/report.py` | דף חישובים E-C01: זרם תכנון, כושר הולכה, מפל מתח מעגל ומצטבר, זרם קצר מינימלי מול סף ניתוק, הנחות וממצאים |
| `bee_cad/server.py`, `bee_cad/web/index.html` | הסטודיו: שרת stdlib ודף אחד בעברית |
| `bee_cad/bom.py` | כתב כמויות → CSV שנפתח באקסל |
| `bee_cad/render.py` | בניית המסמך, PNG תצוגה מקדימה (ezdxf → matplotlib, רקע לבן, bidi) |
| `assets/fonts/shx/` | 100 גופני SHX עבריים מהמשרד (HEBREW, SIVAN, NARKIS, MIRYAM, ORON, TECHNO, …) |
| `assets/plot/` | `SARA.ctb` ו-`DWG To PDF.pc3` מה-eTransmit של הקונסטרוקטור |
| `examples/house_karka.json` | דוגמה: בית מגורים — MDB (20 מעגלים, 3 פחתים, SPD, הזנה לממיר) + לוח חיוני BUB |
